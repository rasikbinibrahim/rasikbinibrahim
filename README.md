## 👨‍💻 About Me

I build **production-grade mobile and web applications** — turning complex product requirements into clean, fast and maintainable interfaces.

- 📱 **Mobile** — Cross-platform apps with **React Native**: biometric authentication, social login, in-app payments, PDF generation and device sensors.
- 🌐 **Web** — **React 18 + TypeScript + Vite + Tailwind CSS**, with a strong eye for UI detail, animation and accessibility.
- 🧩 **Backend-aware** — REST APIs with **Node.js / NestJS**, **PostgreSQL**, **Redis**, deployed on **AWS**.
- 💳 **Integrations** — Razorpay subscriptions and recurring billing, UPI payments, Google &amp; Facebook OAuth.
- 📦 **Open source** — author of the **react-liquid-gauge-typescript** and **react-liquid-rectangle-gauge** React components (MIT).
- 🎯 **Currently building** — **InterviewHub Pro**, a curated frontend-interview knowledge platform for senior and staff-level engineers.
- 💬 **Ask me about** — React Native architecture, React performance, TypeScript and shipping apps to the stores.

## 🧠 How I Work

- **Readable code over clever code** — clear naming, small components, predictable state.
- **Performance by default** — memoisation where it matters, lazy loading, lean bundles and smooth 60fps mobile UI.
- **Reusable building blocks** — design systems, typed component libraries and shared hooks.
- **Shipping** — CI, preview deployments and releases that get features in front of real users.
